# 🏥 Hospital Management Data Analysis & Dashboard

## 📊 Project Overview

This project is an **Excel-based Hospital Management Data Analysis and Dashboard** created to analyze hospital appointment and patient data.

The project includes **data cleaning, data transformation, Excel formulas, Pivot Tables, data analysis, charts, and an interactive dashboard** to generate meaningful healthcare insights.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze total hospital appointments
* Understand appointment status distribution
* Analyze reasons for patient visits
* Compare appointments by doctor
* Analyze monthly appointment trends
* Analyze patient age groups
* Calculate important healthcare KPIs
* Transform raw data into a clean analytical dataset
* Build a professional Excel dashboard

---

## 🗂️ Dataset

The project contains hospital appointment and patient information.

### Main Appointment Data

### Patient Data

## 🧹 Data Cleaning & Preparation

The raw dataset was cleaned and prepared before analysis.

### Cleaning Steps

1. Checked for blank values
2. Checked for missing values
3. Checked for duplicate records
4. Standardized date formats
5. Created a **Full Name** column
6. Calculated **Age**
7. Created **Age Group** categories
8. Prepared the data for Pivot Tables and dashboard analysis

The detailed cleaning process is documented in the **CHANGELOG** sheet.

## 📊 Analysis Questions

### Appointment Analysis

1. How many total appointments are there?
2. How many appointments are completed?
3. What is the appointment status distribution?
4. Which reason for visit has the highest number of appointments?
5. Which doctors have the highest number of appointments?

### Patient Analysis

6. What is the average patient age?
7. What is the maximum patient age?
8. How are patients distributed across age groups?
9. What is the gender distribution of patients?
10. What are the major insurance providers?

### Time Analysis

11. Which month has the highest number of appointments?
12. How do appointments vary by month?
